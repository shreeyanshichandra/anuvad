Upload PDFs, photos, documents or audio, paste text or look up a word in any language, and translate or explain it in the language you choose, with headings, lists and tables kept. Each page is read as an image, so scanned pages and old fonts (like Kruti Dev for Hindi) work too.

Translates plain text on your own computer, with no code and nothing sent to an AI service. It works in Text mode only, and the first use of a language pair downloads a small language pack. Subject, tone, glossary, word limit and Refine need Gemini or Claude.

Claude uses your own Anthropic API key, and Anthropic charges your account for what you use. Claude can read pages and photos, but it can't listen to audio.

Anuvad uses Google's Gemini AI to read and translate pages. It's free: you only need an access code (called an "API key") from your Google account. You do this once.

Get my free code from Google ↗
How do I get it? (2 minutes)
  1. Click Get my free code from Google. A Google page opens in a new tab.
  2. Sign in with your Google (Gmail) account if asked.
  3. If a box asks you to accept the terms, tick it and click Continue.
  4. Click Create API key. If it asks for a project, pick any one shown or let it create one.
  5. A long code starting with AIza appears. Click Copy next to it.
  6. Come back to this tab, paste it in the box below and click Save.

No card or payment is needed. Keep the code private like a password.
